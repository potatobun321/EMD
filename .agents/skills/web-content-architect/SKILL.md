# Web Content Guidelines (VISHWAM)

---

## 1. Identity & Tone

* **Platform Name:** VISHWAM — The Global Dialogue Forum
* **Motto:** *"In Dialogue, We Discover Destiny."*
* **Core Identity:** A youth-driven intellectual and policy platform fostering dialogue, research, leadership, and civilisational exchange.
* **NOT an MUN:** Strictly avoid Model UN / MUN jargon (e.g., *Secretariat*, *Delegate Handbook*, *Committees/Blocs*). Use simple, dignified, and authentic terms: **Conferences**, **Symposiums**, **Roundtables**, **Collaborations**, **Scholars & Changemakers**, **Contact Us**.
* **Simplicity:** Keep writing clear, direct, and purposeful. Avoid generic corporate fluff or artificial buzzwords.

---

## 2. Approved Vocabulary Guide

| Standard Terms to Use | Terms to Strictly AVOID |
| :--- | :--- |
| **Conferences / Symposiums / Roundtables** | Model UN / MUN / Simulated Sessions |
| **Organizing Team / Coordination Desk / Contact Us** | Secretariat / Secretary-General |
| **Participants / Scholars / Young Leaders** | Delegates (unless specifically requested) |
| **Policy Briefs / Research Papers / Monograph** | Resolution Paper / Draft Directive |
| **Collaborations / Academic Partnerships** | Strategic Alliances (overused) |
| **VISHWAM The Global Dialogue Forum** | Generic Summit / Event |

---

## 3. Strict Embargo Policy
* **JAI Conclave**: Do not add or expose any mentions of "JAI Conclave" across active public pages. Keep all copy focused purely on VISHWAM's conferences, symposiums, and dialogues.
